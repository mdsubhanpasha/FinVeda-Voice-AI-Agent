FinVeda-Voice is a real-time, autonomous customer support agent that handles customer calls end-to-end.

Built with a 3-Agent Architecture:
1. Speech-to-Text Agent: Converts customer voice to text using Azure Speech
2. AI Brain Agent: Understands and solves problems using Azure GPT-4o
3. Action Agent: Replies in human voice + triggers automated emails

Key Features:
- Real-time voice conversation
- Fintech domain specific problem solving
- Multi-Agent orchestration
- Deployed with Streamlit

This is not a chatbot. This is the future of Customer Support.
